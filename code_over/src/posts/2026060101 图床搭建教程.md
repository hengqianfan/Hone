## 图床是什么

图床 **（Image Hosting Service）** 是专门用于存储图片并生成网络链接的第三方云端服务器。它的作用就是帮你把图片传到一个专门的服务器上，然后给你一个网络地址（URL），你只需要把这个地址贴到你的文章里，读者就能通过这个地址加载并看到图片，从而减轻本地存储压力。

## Github 图床搭建

**Github** 搭建图床是比较简单的，**但是存在封号的风险**，似乎，这种行为是属于对 Github 滥用。  

::: info 具体步骤

①  在 **Github** 上新建一个代码仓库  

②  把图片放在 **代码仓库** 内  

③  然后，可以使用类似这样的 **https://raw.githubusercontent.com/[yourName]/[yourRepo]/refs/heads/main/repo/[imgName]**  图片链接来访问图片资源  

- [yourName] ：你的 Github 用户名   
- [yourRepo] ： 你的 仓库名   
- [imgName]  ： 你的 图片名 ，带文件后缀   

:::
