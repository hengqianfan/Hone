## 1. 创建项目

::: info

因为使用 **vitepress** 算是写代码，所以需要安装对应的代码环境: **Nodejs** 。

:::

> 新建项目文件夹



> 先安装

```
pnpm i vitepress
```

> 初始化项目

```
npm vitepress init
```

## 部署 - Github 

::: info 说明

对于 **vitepress** 项目如何部署在 **Github** 上，**vitepress** 的官方文档已经给了十分详细的步骤，可以参考:   

- https://vitepress.dev/zh/guide/deploy#github-pages

::: 

::: warning 但是，注意不能无脑套用

- 如果你的项目初始化时，填写的不是 ./docs ，需要修改对应的逻辑

- 如果你的项目使用的包管理器，不是npm，而是其他，需要修改对应的逻辑

- 大概率，你的项目的 base 要进行配置 



:::
