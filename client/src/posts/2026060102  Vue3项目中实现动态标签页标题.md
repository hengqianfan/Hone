::: info 简述

- 在博客网站中，存在一个需求：**将当前页面所渲染的文章的标题，作为浏览器中标签页的标题。**  

> `解决方案` ：在 **Vue3** 项目，比较流行的做法是，将标题定义在 **路由配置** 中，通过 **路由守卫** 监听变化 。
:::

## 1. 固定页面的标签页标题

> 在定义路由配置中增加 meta 属性


```js
const routes = [
  {
    path: '/dashboard',
    component: Dashboard,
    meta: { title: '工作台' }
  },
  {
    path: '/profile',
    component: Profile,
    meta: { title: '个人中心' }
  }
]

```

> 设置规则，让路由跳转到固定页面时，刷新对应的标题

```js
router.afterEach((to: any) => {
  // 1. 如果路由元信息里定义了 title，优先使用
  if (to.meta?.title) {
    setDocumentTitle(to.meta.title);
  }
  else {
    setDocumentTitle('');
  }
});
```
